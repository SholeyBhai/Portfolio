# Rampratap Yadav — Portfolio Starter

A responsive portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — dark theme, responsive layout, visual effects
- `script.js` — mobile navigation and scroll reveal animations

## Before publishing
1. Open `index.html` and replace the placeholder email and GitHub links.
2. Update project cards to link to real repositories or demos.
3. Test locally by opening `index.html` in a browser.
4. Upload these three files to a public GitHub repository.
5. In GitHub, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
7. Wait for the published URL shown on the Pages settings screen.

## Important
- Do not claim skills or projects you cannot explain.
- GitHub Pages hosts static websites; this starter does not include a backend or contact-form processing.
- The Google Fonts link needs an internet connection; fallback system fonts are included.
