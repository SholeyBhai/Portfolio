## Publish updates
1. Extract this ZIP.
2. Open https://github.com/SholeyBhai/Portfolio.
3. Choose **Add file → Upload files**.
4. Upload these four files to the repository root, replacing the old versions.
5. Click **Commit changes**.
6. Vercel should automatically deploy the new commit. Check the latest deployment in your Vercel project.

No build command or environment variables are required for this static website.

Project links currently point to the portfolio repository and the GitHub repositories page. Replace the Java practice link with a specific repository URL when you choose which repo to feature.
